NH 농협은행 모바일 앱 시연용 (이전/다음 버튼 숨김)

- 원본 Figma의 UI 내부 버튼·팝업·화면 전환은 그대로 실행합니다.
- Figma 자체 이전/다음 UI는 hide-ui=1로 숨기도록 설정했습니다.
- Figma 키보드 기본 이전/다음도 disable-default-keyboard-nav=true로 꺼 두었습니다.
- 오른쪽 상단의 작은 ↻ 버튼은 첫 화면으로 돌아갑니다.
- PC 앱 시연 너비는 기존 500px을 유지하고 배경은 검정색입니다.
- 기존에 사용한 앱 주소가 있다면 해당 Netlify 사이트 Deploys에서 이 폴더를 다시 배포하세요.
- 원본 Figma 공유 권한이 필요하고 인터넷 연결이 있어야 합니다.
- Figma iframe 내부의 일부 UI는 Figma 서비스 업데이트에 따라 달라질 수 있습니다.
